# 泳池机器人覆盖率分析（PoolCoverage）

一个给**泳池清洁机器人**做「覆盖率分析」的 Windows 小工具。

你只需要一段**固定机位**拍到的泳池监控视频，在画面上点几下把池底框出来，程序就会自动找出画面里的机器人，
算出它这趟洗了多大面积、哪里漏洗、平均洗了几遍，并生成热力图、轨迹视频和一份结果文件。

- 池底形状不限制：**矩形 / 圆形（椭圆）/ 手绘自定义**，透视变形、异形池、池壁反光都能描边。
- **机位模板**：同一机位拍的多段视频，标定一次保存为模板，换视频一键套用。
- 输出更全：完整轨迹视频 + 两色覆盖图 + 次数热力图 + 覆盖率-真实时间曲线 + 完整轨迹图。
- 纯本地运行：视频不上传、不联网、不需要显卡。
- 界面只有 Tkinter 自带的控件，Windows 10 / 11 双击即用。
- 打包在 GitHub 上自动完成，**你不需要装 Python、也不需要会写代码**。

## 一、把程序打包成 Windows 版（只需做一次）

### 第 1 步：注册 / 登录 GitHub

打开 <https://github.com>，没有账号就先注册一个（免费）。

### 第 2 步：新建一个仓库

1. 点右上角 `+` → **New repository**。
2. **Repository name** 随便填，例如 `pool-coverage`。
3. 选 **Private**（私有，别人看不到你的代码）或 **Public** 都可以。
4. 下面的「Add a README file」「Add .gitignore」「Choose a license」**都不要勾**。
5. 点 **Create repository**。

### 第 3 步：把文件上传到仓库

新建好的仓库页面里点 **Add file → Upload files**，把下面这些**文件和文件夹**拖进去：

```
core.py
app.py
requirements.txt
README.md
.github/workflows/build-windows.yml
```

> ⚠️ `.github` 是隐藏文件夹（名字以点开头），用「拖拽」的方式整个文件夹拖进网页即可。
> 如果浏览器提示不能上传空文件夹或找不到它，用下面的备用方法：
> 在仓库页面点 **Add file → Create new file**，文件名处直接输入
> `.github/workflows/build-windows.yml`（输入 `/` 会自动建文件夹），
> 然后把该文件的内容粘贴进去，点 **Commit changes**。

拖好后点最下面的 **Commit changes**。

### 第 4 步：在 Actions 里一键打包

1. 打开仓库顶部的 **Actions** 标签页。
2. 第一次会看到一个绿色的按钮，点 **I understand my workflows, go ahead and enable them**。
3. 左侧选中 **Build Windows Package**，右边点 **Run workflow ▾ → Run workflow**。
4. 等 3～8 分钟（第一次下载依赖会慢一些），刷新页面，看到绿色的 ✅ 就成功了。

> 如果显示红色 ❌：点进这次运行，展开报错的步骤，把红字截图发出来即可；多数情况是网络超时，

1. 点进**最近一次成功**的运行记录（绿色 ✅ 那条）。
2. 拉到页面最底部，找到 **Artifacts** 区域，点 **PoolCoverage-windows-x64** 下载。

4. 进入解压出来的 `PoolCoverage` 文件夹，双击 **`PoolCoverage.exe`** 就能用。

> 下载 artifact 需要登录 GitHub；如果是在手机上点开链接，会提示登录。
> **不要把 exe 单独拖到桌面**：它需要同目录下的其他文件（包括自带的 ffmpeg.exe），请整个文件夹一起放。

## 二、使用步骤

### 1. 选择视频

点 **浏览…**，选中监控视频（`mp4` / `avi` / `mov` / `mkv` 等常见格式）。
下面会显示分辨率、帧率、总帧数和时长，用来确认视频能被正确读取。

### 2. 选择池型

- **矩形**：方形 / 长方形 / 像四边形的池子。
- **圆形（椭圆）**：圆形、椭圆形池子（斜着拍的椭圆也算）。
- **手绘自定义（透视变形、异形池、池壁反光强时推荐）**：用鼠标沿池底边缘描一圈，程序自动平滑成闭合轮廓。

### 3. 打开画面标定…

点 **打开画面标定…**，会弹出视频的第一帧画面：

**矩形池**：依次点池底的 **4 个角**（顺序随意）。左上、右上、右下、左下这样点最直观。
点够 4 个后屏幕上会显示一个绿色四边形，确认它大致套住池底，点 **确定**。

**圆形池**：依次点 3 个点：

1. 池底**中心**；
2. **长轴端点**（池子较长的那个方向、边缘上的点）；
3. **短轴端点**（与长轴垂直方向、边缘上的点）。

点够 3 个会显示一个绿色椭圆，确认它套住池底，点 **确定**。

**手绘自定义**（透视变形、异形池、池壁反光强时最稳）：

1. 在画面上**按住鼠标左键拖动**，沿池底边缘慢慢描一圈（不要断笔），**松开左键自动闭合**；
2. 程序会立刻用绿色粗线显示平滑后的闭合轮廓，细浅色折线是你刚才的原始笔迹；
3. 轮廓上会出现最多 12 个黄色手柄：拖动某个手柄可以局部微调（每次拖动会用较轻的平滑强度重算）；
4. **平滑强度** 滑块 0～2，默认 1：往左更贴近你描的形状，往右更圆润；
5. **吸附边缘** 默认关闭：勾上后程序会尝试把轮廓吸到池壁/池底交界上。如果发现吸错（吸到水波纹、瓷砖缝），**取消勾选**即可恢复。

手绘满意后点 **确定**，主窗口会显示「已标定（手绘自定义，N 个点）」。

标定窗口里的按钮：

| 按钮 | 作用 |
| --- | --- |
| 清除 / 重画 | 清空已画的点（手绘模式为「重画」），重新来过 |
| 自动识别 | 让程序自动找水面轮廓（矩形/圆形）或初始轮廓（手绘），水色偏蓝、边界清楚时成功率高 |
| 确定 | 保存标定，主窗口显示「已标定」 |
| 取消 | 本次不保存，回到主窗口 |

> 标定完成后主窗口会显示「已标定（矩形，4 个点）」。如果之后**改了池型**，需要重新标定。

### 3.5 机位模板（可选，省时间）

同一个机位、同一片池底，标定一次就够了：

- **保存为模板**：完成标定后点这个按钮，起个名字（默认是当前视频文件名），标定就存下来了；
- **套用**：换一段同机位的新视频时，在「机位模板」下拉框里选名字 → 点「套用」，池型和标定会自动恢复，直接点「开始分析」即可；
- **删除**：选中模板 → 点「删除」，会二次确认；
- 模板文件保存在 `PoolCoverage.exe` 旁边的 `PoolCoverageTemplates` 文件夹（每个模板一个 json）。

> 注意：只有**机位、变焦、池底区域都没变**的视频才能直接套用模板；机位变了请重新标定。

### 4. 设置参数

- **目标类型**：
  - 自动（推荐）：机器人颜色不太确定时用；
  - 暗色机器人：机器人在画面里发黑；
  - 亮色机器人：机器人在画面里发白 / 发亮。
- **灵敏度**：0～1，默认 0.5。0 = 保守（不容易把浪花、反光误认成机器人）；1 = 灵敏（暗光、小目标更容易被找到）。
- **起始时间**（可选）：填监控画面第一帧的时间，格式 `HH:MM:SS`，例如 `08:44:38`。留空则曲线图横轴按「相对时间」（从 0 秒开始）。
- **加速倍数**（默认 1.0）：如果录像被加速过，填加速倍数——例如 2 小时的录像压成 2 分钟，填 60。这样曲线图横轴就是真实时间。

### 5. 开始分析

点 **开始分析**：

- 按钮会变灰，出现进度条和状态文字（例如「检测机器人… 第 120/900 帧」）。
- 分析期间可以点 **取消**，会尽快停下并回到可用状态。
- 想中途算别的视频，先取消或等它跑完。

分析分三步：找机器人 → 计算覆盖面积 → 生成热力图和轨迹视频。视频越长、分辨率越高，耗时越久。

### 6. 看结果

结果区显示 4 个指标：

| 指标 | 含义 |
| --- | --- |
| 覆盖率 | 机器人这趟洗到的池底面积 / 标定的池底总面积 |
| 漏洗面积 | 没被洗到的比例（约等于 100% − 覆盖率） |
| 平均经过次数 | 洗到的地方平均被经过几次（越高说明重复清洗越多） |
| 检测命中率 | 有多少帧找到了机器人（命中率低说明检测没跟上，结果偏差会大） |

下面两行按钮：

第一行：

- **打开输出文件夹**：打开报告目录（每次分析一个带时间戳的子文件夹）。
- **播放轨迹视频**：带机器人检测框、加粗轨迹、起点标记，结尾还会定格 2.5 秒展示完整路径。
- **打开 summary.json**：完整的文字版结果（可用记事本打开）。

第二行是图片按钮（哪张没生成，对应按钮就是灰的）：

- **查看覆盖图**：两色覆盖图，绿色 = 已清洗，白色 = 未清洗。
- **查看热力图**：洗了几遍的颜色图，白色 = 未清洗，蓝 / 黄 / 红 / 黑 = 1 / 2 / 3 / 4 次以上。
- **查看覆盖率曲线**：覆盖率随时间变化；填了「起始时间」时横轴是真实时间，否则是相对时间。
- **查看轨迹图**：一张静态大图，包含池底边界和完整行走轨迹（起点 / 终点有标记）。

### 7. 历史对比

窗口底部会列出以前的分析记录（时间 / 视频 / 覆盖率 / 检测命中率）：

1. 按住 **Ctrl** 键点选**两条**记录；
2. 点 **对比**，会弹出窗口，用两条曲线对比覆盖率随时间的变化（横轴是视频秒数），上方显示两条记录的指标。

点 **刷新** 可以重新扫描输出目录（比如你把旧报告复制进来之后）。

## 三、输出文件说明

每次分析都会在 `PoolCoverageReports`（和 `PoolCoverage.exe` 同目录）下新建一个
`日期时间_视频名` 的文件夹：

| 文件 | 内容 |
| --- | --- |
| `overlay.mp4` / `overlay.avi` | 轨迹视频（池边、机器人框、加粗轨迹、起点标记，结尾定格 2.5 秒展示完整路径） |
| `coverage_map.png` | 两色覆盖图：绿 = 已清洗，白 = 未清洗 |
| `heatmap.png` | 经过次数热力图：白 = 未清洗，蓝 / 黄 / 红 / 黑 = 1 / 2 / 3 / 4 次以上 |
| `coverage_curve.png` | 覆盖率-时间曲线图（填了起始时间 = 真实时间，否则 = 相对时间） |
| `trajectory.png` | 完整轨迹静态图（含起点 / 终点标记） |
| `trajectory.csv` | 机器人轨迹坐标表（可用 Excel 打开） |
| `summary.json` | 全部指标、参数、标定点、覆盖率曲线 |

另外，`PoolCoverageTemplates`（同样在 exe 旁边）保存你存下的机位模板，每个模板一个 json 文件，可以在多段视频之间反复套用。

## 四、常见问题

### 1. 双击后 Windows 拦截 / 杀毒软件报毒怎么办？

PyInstaller 打包的、没有购买代码签名的 exe，经常被 Defender 或国产杀毒软件误报。
程序只在本机读写视频和报告，不联网。

- 在拦截窗口点 **更多信息 → 仍要运行**；
- 或把 `PoolCoverage` 文件夹加入杀毒软件的「信任 / 白名单」；
- 也可以先上传到 <https://www.virustotal.com> 查一下，确认只是误报再放行。

### 2. 提示找不到 ffmpeg / 轨迹视频变成了 `.avi`？

打包好的 zip 里已经自带 `ffmpeg.exe`，正常情况下不会有这个问题。
如果确实缺失：

- 确认 `ffmpeg.exe` 和 `PoolCoverage.exe` 在**同一个文件夹**里（打包后位于 `_internal` 内部也可以）；
- 或者自己下载一个 Windows 版 ffmpeg（<https://www.gyan.dev/ffmpeg/builds/>），把 `ffmpeg.exe` 放到 exe 旁边；
- 没有 ffmpeg 时程序仍能完成分析，只是轨迹视频改用 AVI/MJPG 编码，个别播放器需要额外解码器。

### 3. 标定点错了怎么办？

重新点 **打开画面标定…**：会带上上次的点，直接点 **清除** 或 **自动识别** 重来，最后点 **确定** 覆盖旧标定。
标定错了会直接影响覆盖率的绝对数值（池子框大了覆盖率偏低，框小了偏高），请尽量贴住池底边缘。

### 4. 圆形 / 椭圆形池子怎么点？

点 3 个点：**池底中心 → 长轴端点 → 短轴端点**。
长轴是池子最长的方向，短轴是与它垂直的方向；三个点的连线会显示出来，标定窗口会用绿色椭圆预览。
如果池子是斜着拍的（透视变形），按画面里看到的椭圆点即可，不要按现实中的正圆去点。

### 5. 对录像机位有什么要求？

- 同一段视频里**相机必须固定不动**（不能有人挪动、变焦、切换摄像头）。
- 分析的是「画面里的这块池底」；机位变了就要**重新标定**。
- 水面反光、强逆光、水下灯带会让检测变难，可以调高灵敏度或改用「亮色机器人」再试。
- 建议用俯视/斜俯视、机器人全程在画面内的片段。

### 6. 覆盖率的口径是什么？为什么和别家不一样？

本工具是**像素口径**：

- 池底面积 = 你标定的矩形 / 椭圆 / 手绘轮廓内、且在画面里可见的像素数；
- 机器人每帧的检测框按等效直径 × 0.85 当作「一次清洗扫过的宽度」，相邻帧之间用连线补上；
- **覆盖率 = 被扫过的像素并集 / 池底像素**，所以它是「画面可见池底」的覆盖率，不包括画面之外的部分；
- **漏洗面积 = 1 − 覆盖率**；
- **平均经过次数** 是覆盖区域内平均被扫过几次（重复路径越多越高）；
- 画面边缘、遮挡物（扶梯、浮标）会算在被遮挡的池底里，建议标定时避开。

因为口径是像素口径，分辨率不同的两段视频覆盖率不能直接横向比较；同一个机位、同一标定下比较前后几次清洗才有意义。

### 7. 「自动识别失败，请手动点选」怎么办？

自动识别靠水色（偏蓝、较饱和）找池面，画面偏灰、反光强、水面占据太少时会失败。
直接手动点 4 个角 / 3 个点即可，或改用「手绘自定义」沿池底描一圈，手动标定反而更准。

### 8. 提示「未检测到机器人」怎么办？

- 先确认视频里机器人确实在池底活动；
- 把灵敏度调高（往右拉），或切换「目标类型」为暗色/亮色重试；
- 检查标定是否只框住了池底的一小块，或框到了岸上；
- 机器人太小时可以换更近的机位或更高分辨率再录。

### 9. 分析很久 / 电脑风扇狂转？

分析要读两遍视频并逐帧处理，1080P、10 分钟的视频在普通笔记本上可能要好几分钟。
在分析过程中可以点 **取消**。建议先用 1～2 分钟的短片调好标定和灵敏度，再跑完整视频。

### 10. 下载 artifact 是空的 / 只有 404？

- 请先**登录 GitHub**，未登录不能下载 Actions 的 artifact；
- artifact 默认保留 30 天，过期后重新跑一次 workflow 即可；
- 确认点的是绿色 ✅ 的运行记录，不是失败记录。

### 11. 矩形池在监控角下拍出来是斜的（透视变形），标不准怎么办？

用 **手绘自定义**：沿画面里看到的池底边缘描一圈即可，程序不要求它是标准矩形。
圆形/椭圆池被斜拍变形成椭圆时，「圆形（椭圆）」模式也能处理，但池壁有白边、反光带时，
手绘往往更贴合池底。

### 12. 手绘描边太抖 / 太圆，怎么调？

- **平滑强度**（标定窗口里）0～2：默认 1，调小更贴近手描形状，调大更圆润；
- 把鼠标停在黄色手柄上拖动能局部微调，每次拖动会用 0.5 的轻平滑，不会一下变太圆；
- **吸附边缘** 默认关闭。勾上后会往池壁/池底交界吸附，但实测容易吸到水波纹、瓷砖缝上——
  吸错了取消勾选即可恢复，默认建议手动描。
- 描坏了点 **重画** 重来。

### 13. 换视频不想重新标定？

用 **机位模板**：标定一次后点「保存为模板」，之后换同机位的新视频，下拉框选模板 → **套用**，
池型和标定自动恢复。机位、变焦、裁剪变了就不建议套用，需要重新标定。

### 14. 机位模板存在哪里？可以拷给别人吗？

保存在 `PoolCoverage.exe` 旁边的 `PoolCoverageTemplates` 文件夹，每个模板一个 json 文件。
只要机位和画面尺寸一样，可以直接把这个文件夹拷到另一台电脑的同名目录里复用。

### 15. 覆盖率曲线图的横轴时间是怎么算的？

曲线图横轴 = 起始时间 + 视频播放秒数 × 加速倍数。

- 填了「起始时间」（监控画面第一帧的真实时间）→ 横轴直接显示真实时钟时间；
- 不填 → 横轴从 0 秒开始显示相对时间；
- 录像加速过就填「加速倍数」：例如 2 小时压成 2 分钟填 60，横轴就会还原成 2 小时的真实时间；
- 填错了也不要紧：程序会弹提示，并按相对时间 / 1.0 倍继续分析。

## 五、在电脑上直接跑源码（可选，需要 Python）

1. 安装 Python 3.12（Windows 版，安装时勾选 *Add python.exe to PATH*）。
2. 在本项目文件夹里打开「命令提示符」：

   ```bat
   python -m pip install -r requirements.txt
   python app.py
   ```

3. 想自己打包成 exe（和 Actions 一样的效果）：

   ```bat
   pyinstaller --noconfirm --onedir --windowed --name PoolCoverage --add-binary "ffmpeg.exe;." app.py
   ```

   打包结果在 `dist\PoolCoverage\`，把 `ffmpeg.exe` 一起放进去再运行。
